# Hilt-Engine

**Hilt-Engine** is my **hobby project** written in **C++ 20** and **OpenGL 4.6** – a game engine built with an **Entity Component System (ECS)** architecture.  
This project is primarily for **fun, learning, and self-improvement**.  

---

## Features
- Entity Component System (ECS) architecture,
- Currently supports **OpenGL 4.6**,
- Written in  **C++ 20**,
